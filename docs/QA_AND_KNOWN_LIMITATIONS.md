# 验收状态与已知限制

更新日期：2026-09-03

## 已验证

- 个人计划格式、非法金额、非法日期、重复计划和幂等合并测试通过。
- Vite 生产构建通过。
- 自然月周期、可调整分类预算、计划项目编辑和双存储恢复代码已发布。
- GitHub Pages 最近一次可调整计划版本部署成功。
- 个人计划保存会写入 IndexedDB，并在提示成功前执行回读校验。
- 数据状态同时镜像到 localStorage，用于 iOS 快速挂起或数据库空记录时恢复。

## 每次改动后的最低回归清单

1. 从主屏幕打开，预算与计划仍存在。
2. 快速记一笔后，首页、流水和分类额度同时更新。
3. 退出并重开，流水和计划不消失。
4. 修改一个分类额度，月度总上限自动重算。
5. 修改固定支出金额或日期，重开后仍保留。
6. 定投完成后只增加定投与现金流出，不增加日常消费。
7. 导出备份后，用备份恢复能够还原流水、设置和计划。
8. `?quick=1` 能直接进入金额框。
9. 同一条短信重复进入不会生成重复流水。
10. 在线打开一次后，断网仍能启动基本页面。

## 已知限制

- iOS 主屏幕应用与 Safari 标签页可能不共享数据容器。
- 删除主屏幕图标、清除 Safari 网站数据或系统回收网站存储仍可能造成数据丢失；iCloud 文件备份是最终保障。
- 当前没有账号、服务器数据库或跨设备同步。
- iPhone 不允许普通网页直接读取全部短信；必须依赖用户建立的快捷指令自动化。
- 浏览器通知能力受 iOS 版本、主屏幕安装状态和通知权限限制。
- 短信文本格式由银行决定，格式变化可能降低金额或分类识别率。
- 初始计划说明是历史依据，用户修改后的实时金额以“调整个人计划”编辑区为准。
- TypeScript 全量检查仍有旧 PDF 解析器中的 `document` 变量遮蔽错误；生产构建可完成，但后续应单独修正。
- “清空本机数据”当前实际只清空交易流水，按钮文案与实际范围仍应进一步统一。

## 安全要求

- 不在公开仓库写入私人金额、家庭资料、真实账单、短信原文或私人启用链接。
- 不以修复为由清空浏览器数据、删除应用或重置 Git 历史。
- 涉及删除计划、流水或备份的功能必须提供明确确认和可恢复路径。
